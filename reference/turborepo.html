Referência rápida

Turborepo em uma página

Camadas do workspace

apps/*       aplicações implantáveis
packages/*   código reutilizado e ferramentas
package.json declara workspaces, scripts e ferramentas
turbo.json   orquestra, prevê dependências e cacheia tasks

Dependências das tasks

"dependsOn": ["^build"]  builds das dependências primeiro
"dependsOn": ["build"]   outro script do mesmo pacote primeiro
outputs                  arquivos que o cache restaura
inputs                   arquivos que mudam o hash
cache: false             task que não deve ser reutilizada
persistent: true         processo longo, como dev/serve

Comandos úteis

npm run build
npx turbo run build --filter=web
npx turbo run build --filter=web...
npx turbo run build --dry=json

...dependencies inclui dependências; o operador é explicado pela sintaxe de filtros da CLI. Reinicie este monorepo pela raiz.

Deploy

  1. Crie um projeto de plataforma para cada aplicativo implantável.
  2. Aponte a Root Directory para apps/web, por exemplo.
  3. Execute o build pela raiz quando necessário para resolver dependências internas.
  4. Declare env vars que alteram builds em turbo.json e configure-as na plataforma.
  5. Implante cada aplicativo independentemente; isso não exige publicá-lo no pacote registry.
